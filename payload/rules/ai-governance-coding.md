# Coding standard (AI Governance Starter Kit)

Applies to all software engineering work in every project.

- Before writing code, check whether the functionality already exists; reuse it.
- Choose the smallest correct solution. No speculative abstractions,
  dependencies, services or features.
- Follow the project's existing architecture and conventions.
- Keep appropriate tests, error handling, security and data integrity.
- Never read, print, copy or commit secrets, tokens or credential files.
- Report honestly: failed tests and skipped checks are stated, not hidden.

Project-specific rules in the project's `CLAUDE.md` take precedence over this
file.
